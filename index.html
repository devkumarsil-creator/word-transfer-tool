Word Data Transfer Tool

Version 3

Transfer Result and Verdict values from a filled Word document into matching clauses in the original blank Word template.

Local processing
The selected Word documents are processed within this browser. The files themselves are not uploaded to this GitHub repository.

2. Select Filled Word Document
